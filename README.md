# ACM–VIT Cyberpunk room

A desktop-only, full-screen scene based on the supplied PS5/TV/cabinet reference. Small screens and devices without a mouse or trackpad receive the computer-only fallback.

## Run

```sh
npm install
npm run dev
```

Press the PS5 power button. Its lights come on, the TV displays the PlayStation and ACM–VIT marks, and the camera pulls back to the room. Hover over the Cyberpunk case in the open cabinet shelf, then click the exposed disc to insert it into the console. The TV launches the animated Cyberpunk home with App, Web, FOSS, and DevOps selections. TV edge colors drive the twelve sections of wall lighting.

## WebAssembly assets

All room geometry is embedded in `public/assets/room.wasm`, which exports its asset bytes through WebAssembly memory. Every mesh inside the module is Draco-compressed and decoded by the local WebAssembly Draco decoder. The model build validates that every primitive has Draco compression. No runtime model geometry is generated by the application.

`npm run models` rebuilds the WASM module from `scripts/scene-source.mjs` and the console geometry source. `npm run build` regenerates the models and builds the static website; `npm run preview` serves that build.

The game display and case use the supplied Cyberpunk artwork. The ACM mark is the supplied image. The 3D geometry is a visual reconstruction from reference photographs.

Temporary screenshots, local notes, build output, and dependencies are ignored by Git.
